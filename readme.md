
# Zomato Restaurant Data Analysis & ML Prediction

## Project Overview
Exploratory Data Analysis and Machine Learning project
using 9,551 Zomato restaurant records.

The goal is to analyze restaurant trends and predict
whether a restaurant offers online delivery.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
- Logistic Regression
- Random Forest
- Extra Trees

## Best Model Random Forest

 Metric  Score 
------
 Accuracy  80.64% 
 ROC-AUC  0.8835 
 Precision (Yes)  59.58% 
 Recall (Yes)  76.12% 
 F1-score (Yes)  66.85% 

## Methodology
1. Data cleaning and preprocessing
2. Exploratory Data Analysis
3. Feature selection and leakage prevention
4. Train-test split (8020)
5. Five-fold cross-validation
6. Model comparison and evaluation

## Dataset
Zomato restaurant dataset containing 9,551 records.
